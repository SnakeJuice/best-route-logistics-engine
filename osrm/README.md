# 🗺️ OSRM Map Data Setup

This directory holds the Open Source Routing Machine (OSRM) data files.

### 📥 Downloading Map Data

To process routing for a specific region (e.g., Chile / South America), download the `.osm.pbf` file from Geofabrik:

```bash
# Example: Download Chile region map data
curl -L -o osrm/map.osm.pbf [https://download.geofabrik.de/south-america/chile-latest.osm.pbf](https://download.geofabrik.de/south-america/chile-latest.osm.pbf)
```
